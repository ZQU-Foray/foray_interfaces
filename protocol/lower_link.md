# 上位机 ↔ 下位机通讯协议

> 机器可读定义 [`lower_link.yaml`](lower_link.yaml)（**唯一事实来源**），内容层代码由
> [`../scripts/gen_lower_link.py`](../scripts/gen_lower_link.py) 生成——**禁止手写**。
> **帧格式**（怎么发送与接收）不属本文档，归链路实现。

## 1. 消息表

⬜ **待填写** —— 由**算法组与电控组共同确定**，本仓不预设。

| ID | 名称 | 方向 | 周期 | 载荷 |
|---|---|---|---|---|
| `0x__` | `NAME` | 上→下 | __ Hz | `field`（float32, rad, body） · … |

**每条消息**：`ID` · `名称`（全大写下划线）· `方向` · `周期`（`0` = 事件触发）· 载荷字段。
`ID` 按方向分段：`0x00-0x0F` 上→下 · `0x10-0x1F` 下→上 · `0x70-0x7F` 链路管理。

**每个字段必须写清**：

| 项 | 规定 |
|---|---|
| 语义 | 这个数是什么 |
| 类型 | `float32` · `uint8` / `uint16` / `uint32` · `int16` · `bool`；数组写 `float32[4]` |
| 单位 | SI 单位；角度用弧度 |
| 坐标系 | 遵循 **REP-103 / REP-105**。云台角**全队统一**：**yaw 向左为正、pitch 向下为正**（与 DJI NED 约定不同，在本仓写死） |
| 取值范围 | 物理上限，不是类型上限 |
| 缺失时如何表示 | 逐字段规定（标志位 / 哨兵值）。**估计类字段必须带置信度** |

## 2. 字节表示

| 项 | 规定 |
|---|---|
| 字节序 | 全部**小端** |
| 浮点 | **IEEE 754 单精度**；禁用 `double`（MCU 无硬件双精度） |
| 结构体对齐 | `#pragma pack(1)`，无隐式填充 |
| 角度 | `float` 弧度 |
| 长度 | **禁变长字段**（字符串 / 变长数组）——载荷长度必须是编译期常量 |
